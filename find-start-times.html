Find Audio Start Times

Instructions:

1. Play each audio file and listen for when the actual sound begins

2. Use the audio player controls to find the exact time (in seconds) where sound starts

3. Enter that time in the "Start Time" field

4. Click "Test Start Time" to verify it starts at the right place

5. Once you've set all start times, click "Copy All Values" at the bottom

6. Paste the values into timeline-horizontal.html to replace the songs array
